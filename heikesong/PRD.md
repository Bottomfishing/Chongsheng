# Web剧情动画（互动剧情）MVP — PRD

版本：v0.1（PC / Vue3 / 本地视频 / 一次A/B分支）

## 1. 项目目标
做一个PC端可运行的互动剧情网页：
- 主页进入游戏
- 播放一段视频
- 视频结束出现一次 A/B 选择按钮
- 选择后进入对应分支视频，并到达结尾页
- 自动存档：刷新页面不丢进度（localStorage）

## 2. 用户流程（MVP）
1) 用户访问首页 `/`
- 显示：标题/封面（可选）/“开始游戏”按钮

2) 点击“开始游戏”进入 `/play`
- 进入剧情起点节点（startNode）

3) 视频节点（Video）
- 播放当前节点配置的视频文件
- 视频播放结束后自动进入 next 节点

4) 选择节点（Choice）
- 显示提示文案（可选）
- 显示两个按钮：A / B
- 点击后跳转到对应分支节点

5) 结尾节点（Ending）
- 显示结尾标题/文本（可选）
- 操作按钮：返回主页 / 重新开始

## 3. 范围与约束
### 3.1 本期做（In Scope）
- Vue3 SPA（仅前端）
- 路由：`/`、`/play`
- 剧情脚本驱动（JSON）
- 节点类型：video / choice / ending
- localStorage 自动保存与恢复

### 3.2 本期不做（Out of Scope）
- 跳过/快进/倍速/自动连播设置
- 对白框、立绘、背景图、音效
- 多次选择、多条件跳转、复杂变量系统
- 后端、账号、云存档、数据统计

## 4. 资源要求
- 视频以本地文件形式放入项目（例如 `public/videos/*.mp4`）
- 浏览器支持常见格式（优先 mp4/h264）

## 5. 存档/恢复规则（MVP）
- 自动保存：每次节点变化（goto）写入 localStorage
- 自动恢复：
  - 若 localStorage 有有效 nodeId，则进入 `/play` 时从该 nodeId 恢复
  - 若不存在或脚本不匹配，则从 startNode 开始
- 重新开始：清空存档并回到 startNode

## 6. 验收标准
- 从首页能完整跑通：主页 → video_1 → choice(A/B) → video_A 或 video_B → ending
- 刷新 `/play` 能恢复到刷新前所在节点（至少恢复 nodeId）
- 修改 story.json（例如替换视频src/调整next）不改代码也能改变剧情走向（在现有节点类型内）
